Destaque

Leitor Interativo de Histórias e Músicas Infantis

Aplicação web desenvolvida para proporcionar uma experiência imersiva de leitura e audição de histórias e faixas musicais para os meus filhos.

  • Tecnologias: SQLite embarcado no navegador via sql.js (WASM), JavaScript puro, interface responsiva.
  • Recursos: Destaque dinâmico de texto sincronizado com áudio, navegação offline por dados locais.
